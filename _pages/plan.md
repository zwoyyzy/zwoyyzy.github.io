# 未来规划

## 一、我的总体目标

大学接下来的三年，我希望在打好计算机专业基础的同时，逐步提高自己的编程能力、软件开发能力和项目实践能力，并进一步探索自己感兴趣的技术方向。

目前我比较感兴趣的方向包括：

- 计算机视觉
- 深度学习
- 大语言模型
- 软件开发

希望通过课程学习、个人实践和项目经历，逐渐明确自己未来的发展方向。

---

## 二、为什么制定这个目标

目前我的专业知识和实践经验还在不断积累的阶段，对于未来具体从事什么方向还没有完全确定。

因此，我希望在大学剩余时间里，通过学习不同的专业课程和参与不同类型的项目，逐渐了解自己的兴趣和优势。

我认为目前最重要的不是过早确定一个固定的职业方向，而是先打好专业基础，提高自己的学习能力和实践能力，再根据实际学习和项目经历逐步做出选择。

---

# 三、未来三年规划

## 第一阶段：基础能力提升

### 时间：第一年

这一阶段的主要目标是进一步巩固计算机专业基础知识，提高编程能力。

计划完成：

- 学习和巩固常用编程语言
- 加强数据结构与算法基础
- 学习数据库相关知识
- 学习软件工程基本知识
- 熟悉 Git / GitHub 等开发工具
- 完成更多编程练习和课程项目
- 培养良好的代码规范和学习习惯

### 阶段目标

希望能够独立完成一些中小型程序，并能够比较规范地进行代码编写、调试和项目管理。

---

## 第二阶段：项目实践与方向探索

### 时间：第二年

这一阶段希望从基础学习逐渐转向更加深入的项目实践。

计划：

- 参与课程项目和团队项目
- 尝试独立完成一些小型项目
- 学习 Web 开发及相关技术
- 进一步学习人工智能相关知识
- 尝试计算机视觉、深度学习或大语言模型相关实践
- 积累 GitHub 项目和个人作品
- 提高团队协作和沟通能力

### 阶段目标

希望能够独立承担一个项目中的部分功能，并能够从需求分析、设计、编码到测试完成比较完整的软件开发流程。

同时，通过不同方向的实践，进一步判断自己更适合和更感兴趣的技术方向。

---

## 第三阶段：确定方向与发展

### 时间：第三年

这一阶段希望逐渐明确自己的未来发展方向。

根据前两年的学习和实践情况，我计划重点选择一个自己比较感兴趣的方向进行深入学习。

可能的发展方向包括：

- 人工智能
- 计算机视觉
- 深度学习
- 大语言模型
- 软件开发

计划：

- 深入学习目标技术方向
- 完成一个相对完整的个人或团队项目
- 整理自己的项目和学习成果
- 完善 GitHub 个人主页和项目仓库
- 根据自己的实际情况准备升学或就业
- 进一步了解目标行业和岗位的能力要求

### 阶段目标

希望在毕业前形成比较清晰的职业发展方向，并具备一定的专业竞争力。

---

# 四、升学 / 就业规划

目前我还没有完全确定毕业后的具体选择。

### 如果选择继续升学

如果在大学学习过程中发现自己对人工智能、计算机视觉、深度学习等方向有较强兴趣，并且希望进行更加深入的学习，我会考虑继续攻读研究生。

在本科阶段，我会努力打好专业基础，并通过课程学习、项目实践和相关技术学习，为后续升学做好准备。

### 如果选择就业

如果未来更倾向于直接就业，我希望寻找与软件开发或人工智能相关的岗位。

在此之前，我会重点提升：

- 编程能力
- 数据结构与算法
- 软件工程能力
- 项目开发经验
- 团队协作能力
- 实际问题解决能力

并通过项目作品和实践经历提高自己的求职竞争力。

---

# 五、我希望达到的状态

通过未来三年的学习，我希望自己能够：

- 掌握较扎实的计算机专业基础知识
- 具备独立编程和解决问题的能力
- 能够参与完整的软件项目开发
- 具备一定的团队协作经验
- 掌握 Git / GitHub 等常用开发工具
- 对人工智能相关技术有一定了解和实践经验
- 找到自己比较感兴趣的技术方向
- 对毕业后的升学或就业选择有比较明确的规划

---

# 六、我的长期目标

我的长期目标是成为一名具有较强实践能力和持续学习能力的计算机专业人才。

目前我比较关注**人工智能与软件开发**两个方向，希望在未来的学习过程中不断尝试和探索，并根据自己的兴趣、能力和实践经历逐步确定最终的发展方向。

我希望自己不仅能够学习理论知识，也能够将所学知识应用到实际项目中，通过不断实践提升解决真实问题的能力。
